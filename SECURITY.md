# Security

Report suspected vulnerabilities privately to `[CONTACT_EMAIL]`. Do not include secrets or exploit details in public issues.

Incident response placeholder: contain the incident, assess affected data and users, document actions and evidence, preserve relevant audit logs, and obtain qualified legal advice about any required notifications.

Security-sensitive administrator actions and moderation decisions are recorded in `audit_logs`. Supabase RLS is deny-by-default at the table level and moderator access is separate from normal-user access.
