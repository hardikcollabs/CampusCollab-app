# Contributing

Thanks for helping make CampusCollab useful and safe for students.

1. Create a focused branch from `main`.
2. Keep changes accessible, mobile-friendly, and typed.
3. Never add emails, phone numbers, credentials, or other personal data to seed data.
4. Run `npm run lint` and `npm run build` before opening a pull request.
5. Explain any schema or RLS change in the pull request description.

Please report security issues privately rather than opening a public issue with exploit details.
